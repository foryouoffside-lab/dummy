## 1. Overview & Search Architecture
Choice Reaction Time (CRT) evaluates perceptual discrimination speed, decision latency, and motor response execution under rapid rule-switching pressure (Donders, 1868). Unlike Simple Reaction Time (SRT, ~200ms), which only requires a motor release to a single expected stimulus, CRT introduces an information-processing stage where the central nervous system must discriminate between multiple stimulus-response alternatives. According to the Hick-Hyman Law (Hick, 1952; Hyman, 1953), reaction time increases logarithmically as the number of choices expands ($RT = a + b \cdot \log_2(n)$). This drill further challenges executive cognitive flexibility by unpredictably inverting active color rules during gameplay, measuring the prefrontal cortex's ability to override habitual responses.
