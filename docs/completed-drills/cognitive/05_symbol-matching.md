## 1. Overview & Search Architecture
The Symbol Digit Modalities Test (SDMT) is a premier clinical neuropsychological assessment designed by Aaron Smith (1973) to measure cognitive information processing speed, visual scanning efficiency, and short-term associative memory. Unlike pencil-and-paper Digit Symbol Substitution Tests (DSST) from the Wechsler battery, the digital adaptation neutralizes motor-graphical confounds (such as hand tremor or handwriting friction), isolating pure cortical processing speed. Performers cross-reference an active reference matrix pairing geometric symbols with numerical digits (1–9). As associative memory strengthens, response latency drops toward pure motor decision limits.
