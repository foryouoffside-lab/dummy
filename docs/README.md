# Documentation

Working notes for the project. None of this is served to the web — Next.js only
routes `app/` and serves static files from `public/`, so nothing under `docs/`
is crawlable and none of it affects search rankings. It exists for humans and
agents reading the repo.

`README.md` and `AGENTS.md` stay at the repo root by convention.

## [drill-research/](drill-research/) — 80 per-drill audits

One `*_RESEARCH_SUMMARY.md` per drill: search landscape, competitor gaps, the
science cited on the page, and the schema/copy changes made. These are the
**narrative** write-ups.

The **raw measured data** they are built from lives separately in
[`scripts/keywords/out/`](../scripts/keywords/out/) — one report per drill,
straight from the Bing Webmaster API. Where a summary and its raw report
disagree on a volume figure, the raw report is the measurement and the summary
is the claim; trust the raw report.
