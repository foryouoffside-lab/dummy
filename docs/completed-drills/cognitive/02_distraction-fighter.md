## 1. Overview & Search Architecture
The Stroop Color-Word Interference Test is the gold standard paradigm in cognitive neuropsychology for assessing selective attention, cognitive flexibility, and executive inhibitory control (Stroop, 1935; MacLeod, 1991). In this drill, color names appear rendered in mismatched ink hues (e.g., the word "RED" displayed in neon blue font). Because word reading is an automatic, overlearned cognitive process, the brain naturally generates an early semantic lexical response. The performer must actively suppress this automatic reading impulse via dorsolateral prefrontal (DLPFC) and anterior cingulate (ACC) activation, resolving conflict to select the physical ink color under strict time limits.
