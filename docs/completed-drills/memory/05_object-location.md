## 1. Overview & Scientific Foundation

The **Object Location Memory Test (OLM)** evaluates the cognitive mechanism of binding visual object identity ("what") to exact spatial grid coordinates ("where"). Unlike simple pattern memorization, object location tasks require the integration of the ventral stream (object features) and dorsal stream (spatial layout) within the parieto-hippocampal network.

### Key Literature & Theoretical Foundations:
- **Silverman & Eals (1992, 1994)**: *The hunter-gatherer theory of human spatial sex differences: Object location memory* – Pioneer study showing distinct evolutionary mechanisms for static object-location recall versus dynamic mental rotation.
- **Postma & De Haan (1996)**: *What was where? Memory for object locations* – Formalized the distinction between positional memory, object identity memory, and object-to-position binding.
- **Ungerleider & Mishkin (1982)** / **Goodale & Milner (1992)**: The two-stream visual hypothesis (ventral "what" vs. dorsal "where").
- **Luck & Vogel (1997)**: Visual working memory capacity of ~4 integrated feature tokens.
- **Woods et al. (2015)**: Browser chronometry and hardware refresh quantization.
