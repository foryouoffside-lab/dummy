## 1. Overview & Search Architecture
The Color Memory Game (Simon Sequence Test) assesses the capacity and retention fidelity of visual working memory and the visuospatial sketchpad (Baddeley & Hitch, 1974). According to visual working memory capacity benchmarks (Luck & Vogel, 1997; Cowan, 2001), the human brain can reliably maintain approximately 3 to 4 independent visual items simultaneously in its uncompressed focus of attention. To process sequences exceeding this threshold, the central executive must deploy mental grouping strategies, known as chunking (Miller, 1956), pairing chromatic and auditory cues into unified cognitive units. By expanding the classic 4-color Simon paradigm to 6 dynamic chromatic panels, this drill elevates choice entropy and provides an ecologically valid benchmark for testing cognitive endurance, sequential recall, and working memory span under speed pressure (Woods et al., 2015).
