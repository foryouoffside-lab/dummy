## 1. Executive Summary & Intent Definition

The **Keyboard Tester** is a hardware diagnostic utility designed to solve a specific, high-urgency user problem: *"Is my key broken, stuck, or ghosting?"*

### Search Intent Clarification:
* **Intent Type:** Technical Hardware Diagnostic (NOT typing speed, WPM, or aim training).
* **Searcher Persona:** Gamers experiencing key chatter/stuck keys, remote workers checking laptops, and mechanical keyboard enthusiasts verifying key rollover (NKRO) and custom layouts.
* **Separation of Concerns:** Distinct from `/drills/motor/movement-speed/keyboard-recognition` (which trains esports keybind reaction speed). The two must NEVER be merged.

## 4. Market-Specific Strategic Findings & Authority Reality Checks

### 1. 🇧🇷 Brazil (`pt-BR`) — Priority #1
* **Evidence:** Bing reports an exact-match demand of **10,329/mo** for `teste de teclado` and **6,494/mo** for `teste teclado`. Combined with online modifiers (`teste de teclado online` at 3,517/mo), the Brazilian cluster represents over **23,000 monthly exact-match queries**.
* **SERP Reality:** Local Brazilian sites (`testeteclado.com.br`) rank because they offer the **ABNT2 layout** (the Brazilian standard featuring the `Ç` key). However, their pages suffer from aggressive advertising, lack Core Web Vitals optimization, and offer zero event diagnostic tools.
* **Execution Moat:** Provide a fast, modern tool with an explicit **ABNT2 layout toggle** and anti-ghosting test.

### 2. 🇰🇷 South Korea (`ko-KR`) — Priority #2
* **Evidence:** Bing reports an exact-match demand of **2,201/mo** for `키보드 테스트`, with secondary terms (`키보드 테스트 사이트` 218/mo, `키보드 입력 테스트` 209/mo) establishing a total cluster of **~2,600/mo**.
* **SERP Reality:** *The Korean SERP currently shows limited native-language competition, creating a potentially favorable localization opportunity. Ranking probability must be validated through page-level SERP and authority analysis.* Foreign sites (`key-test.com`, `keyboardtester.com`) rank despite forcing users to switch their operating system layout to English US.
* **Execution Moat:** Provide native Korean UI strings, Hangul (Du-beol-sik) key recognition, and direct Korean AEO answer blocks.

### 3. 🇫🇷 France (`fr-FR`) — Priority #3
* **Evidence:** Discovered via native terminology search (`test clavier`) with **1,329 exact-match /mo** reported in Bing and active Google Suggest validation.
* **SERP Reality:** French users operate on the **AZERTY** physical layout. Foreign QWERTY tools fail to accurately map number row shifts and accented keys.
* **Execution Moat:** Provide an **AZERTY layout toggle** on `/fr/drills/motor/keyboard-tester`.

### 4. 🇯🇵 Japan (`ja-JP`) — Priority #4
* **Evidence:** Bing reports **540/mo** for `キーボード テスト`.
* **SERP Reality:** Highly focused community searching specifically for **`日本語配列`** (JIS layout) and **`チャタリング`** (key bounce/chattering).
* **Execution Moat:** Add a key bounce/chatter counter and JIS layout toggle.
