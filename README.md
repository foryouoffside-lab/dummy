# SkillDrills

A comprehensive platform for cognitive and motor skill training with 120+ interactive drills.

## Features

- 🎯 120+ Interactive Drills
- 🧠 Cognitive Training
- 🎮 FPS Gaming Drills
- 👁️ Visual & Motor Skills
- 📚 Academic Drills
- ⚡ No Login Required
- 💾 Local Score Storage

## Categories

- FPS Gaming (240fps/360fps reaction training)
- Cognitive (Memory, Focus, Problem-solving)
- Visual (Reaction speed, Tracking, Recognition)
- Motor (Hand-eye coordination, Precision)
- Academic (Math, Reading, Writing)
- Productivity (Task switching, Time management)
- Mental Fitness (Meditation, Stress control)
- Physical (Balance, Reflex, Coordination)

## Tech Stack

- Next.js 14
- React
- Tailwind CSS
- LocalStorage for scores

## Deployment

This app is deployed on Vercel and requires no database or authentication.
