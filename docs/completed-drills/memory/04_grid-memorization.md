## 1. Overview & Scientific Foundation

The **Visual Memory Test (Grid Pattern Memorization / Memory Matrix)** evaluates the capacity and retention of the visuo-spatial sketchpad, specifically isolating the passive "visual cache" from sequential motor rehearsal. Users memorize flashed patterns on expanding grids (from 4x4 to 5x5) within 1.5 seconds, challenging visual chunking and spatial pattern reconstruction.

### Key Literature & Theoretical Foundations:
- **Luck & Vogel (1997)**: *The capacity of visual working memory for features and conjunctions* – Established the fundamental visual working memory limit of ~4 integrated visual objects.
- **Logie (1995)**: *Visuo-spatial working memory* – Delineated the passive visual cache (form/color/static layout) from the active inner scribe (spatial movement planning).
- **Della Sala et al. (1997, 1999)**: *Visual Patterns Test (VPT)* – Standardized static matrix recall to measure visual short-term memory capacity independent of sequential pathways (unlike the Corsi blocks).
- **Cowan (2001)**: *The magical number 4 in short-term memory* – Formalized capacity limits in working memory chunks.
- **Woods et al. (2015)**: High-resolution millisecond browser chronometry and timing standards.
